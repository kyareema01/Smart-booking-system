# Smart Scheduler Library

A simple full stack booking system for a cleaning service that allows customers to book services based on **service type, size, and dirt level**.

---

## Features

-  Book cleaning services (House, Couch, Rug)
-  Select size (Small, Medium, Large)
-  Choose dirt level (Light / Heavy)
-  Dynamic pricing based on selection
-  Smart scheduling with availability check
-  Auto-suggest next available slot
-  Prevents double booking (transaction-based)

---

## Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** Node.js, Express
- **Database:** MySQL
